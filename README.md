# LC Fantasy Cricket App

Clickable prototype of a fantasy cricket game for SA20 Season 5 (2027), built on Fantasy Premier League mechanics.

**Live demo:** https://yadahbrooks-jpg.github.io/leecoller-fantasy-cricket/

Demo login: username `Lee.test`, password `123` (mock only, no real authentication).

## What's in it
- Opening animation, mock sign-in / sign-up, spinning-ball loader
- Home dashboard: stats, gameweek strip, your XI on a cricket field
- 15-player squad builder (100-credit budget, max 3 per franchise), starting XI, captain and vice-captain
- Five simulated gameweeks, transfers with points hits, an 8-team mini-league

## Data notes
Squads are the SA20 2027 squads after the 7 October 2026 auction (as reported by Wisden). Player roles, prices, fixture order and match results are prototype values generated by the app. Scoring follows the Dream11 T20 points system. Everything is stored in the viewer's browser.
